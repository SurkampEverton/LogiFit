## Mudanças desde v0.1

### Implementado nesta Sprint 06

1. **Classifier de input + output** (ADR 0015 publicado nesta sprint):
   - Input: anti-prompt-injection (5 padrões — ignore previous, system fake, code exec, etc)
   - Output: prescrição (5 padrões — "tome 500mg", "prescrevo X", "use Y mg" em pt/en/es) + diagnóstico (3 padrões — "você tem X", "diagnóstico confirmado") + termos proibidos (4 padrões — "atestado médico", "receituário")
   - Bloqueio dispara `ai_audit_log.guardrail_blocked=true` + mensagem fallback persona-aware (`getBlockedOutputMessage(reason)`)
   - 18 unit tests verdes em `packages/ai/src/classifier.test.ts`

2. **PII redaction** (`redactBeforeLLM`):
   - Cobre CPF (mantém verificadores), CNPJ (mantém filial), RG, email (mantém domínio), telefone BR (mantém DDD), cartão (últimos 4), PIX UUID, CEP (mantém região)
   - 12 unit tests verdes em `packages/ai/src/redact.test.ts`
   - Aplicado em `sendMessage` Server Action antes de qualquer envio a provider

3. **7 personas** com prompts em pt-BR/en-US/es-419:
   - `member`, `professional_clinical`, `professional_coach`, `admin`, `recepcao`, `super_admin`, `contador_externo`, `dpo`
   - `inferPersona(roles, isMember)` mapeia role → persona default
   - Disclaimer fixo "sugestão auxiliar — profissional humano decide" no sheet (regra 28)

4. **Tool registry distribuído** (`registerAITool` / `getAvailableTools`):
   - 9 tools whitelist inicial registradas em `apps/web/app/lib/ai-tools.ts`
   - 3 tools bloqueadas explicitamente (members.delete LGPD art.18 / fisio.signEvolution ICP-Brasil / financeiro.chargeBatch fluxo dedicado)
   - Filtro por persona + permission + vertical + whenAvailable

5. **Camada 3 com proteção dupla** (ADR 0075):
   - `proposeAction` cria row em `assistant_action_proposals` state=`pending` com expiração 5min
   - `<ActionConfirmDialog>` mostra título/descrição/impacto/affectedEntities
   - `POST /api/ai/proposals/:id/confirm` valida estado + tenant + user (autor) antes de marcar `confirmed`
   - Sprint 06+ Faixa C real: handler de tool exige `proposal_id` confirmado pra executar

6. **Cota mensal por plano** (ADR 0066):
   - `checkQuota(ctx, usage)` retorna snapshot com `blocked`/`softWarning`
   - Hard-stop em 100% mensal lança `AI_QUOTA_EXCEEDED` (envelope ADR 0071) com CTA "Configure BYOK"
   - Soft daily warn em `dailySoft` (1/10 do mensal)
   - `bumpUsage` incrementa `ai_tenant_usage` por (tenant, month)

7. **Audit log persona-aware**:
   - Cada turn grava `ai_audit_log` com `persona`, `layer`, `task`, `model_slug`, `provider_slug`, tokens, latência, `guardrail_blocked`
   - Append-only via policy SQL (RLS bloqueia UPDATE/DELETE)

8. **UI mínima entregue**:
   - `<AssistantFAB>` 56px mobile / 64px desktop em todo `/app/*` + atalho Ctrl/Cmd+/
   - `<AssistantSheet>` side panel 420px com header (persona chip), body (bubbles), input textarea, footer com disclaimer + cota visual
   - `<ActionConfirmDialog>` Camada 3
   - Páginas `/app/assistente`, `/app/settings/ia`, `/app/suporte`, `/app/super-admin/ai-usage`

### Diferimentos vs v0.1 (próximos PRs)

- **LLM real**: `sendMessage` ainda usa stub eco persona-aware. Sprint 06+ Faixa C real conecta Vercel AI SDK + `resolveModelForTask()` com GEMINI_API_KEY ENV.
- **RAG seed**: schemas `ai_documents`/`ai_document_chunks`/`ai_semantic_cache`/`member_insights` criados + RLS + HNSW indexes; job `SeedRAGSystemDocuments` (ADRs/sprints/regulações) fica como próximo PR.
- **BYOK UI write**: read-only no MVP (lista providers + status). Form de upload de key com `encryptSecret()` (envelope-crypto AES-256-GCM) fica como próximo PR.
- **White-label name**: hook `useAIAssistantName()` ainda hardcoded `'Copilot'`. Sprint 06+ lê `tenant_settings.assistant_name`.
- **Anti-abuse 10x avg**: ADR 0073 camada 5 — fica para próximo PR.

## Princípios de segurança ativos hoje

| Camada | Controle | Onde |
|---|---|---|
| Input | Anti-injection classifier | `packages/ai/src/classifier.ts` |
| Input | PII redaction CPF/CNPJ/RG/email/phone/cartão/PIX/CEP | `packages/ai/src/redact.ts` |
| Routing | Resolver com priority cascade Gemini → Anthropic → OpenAI | `packages/ai/src/resolver.ts` |
| BYOK | Envelope encryption AES-256-GCM (chave em ENV) | `@repo/security/envelope-crypto` |
| Output | Prescription/diagnosis/prohibited-term classifier | `packages/ai/src/classifier.ts` |
| Tool gate | Whitelist registry + persona/permission/vertical filter | `packages/ai/src/registry.ts` |
| Camada 3 | Proposta → ConfirmDialog → handler-side `proposal_id` requirement | `assistant_action_proposals` + `confirmProposal` |
| Cota | Hard-stop mensal por plano + circuit breaker | `packages/ai/src/quotas.ts` + `checkQuota` |
| Audit | `ai_audit_log` append-only com `persona`/`layer`/`guardrail_blocked` | RLS policy + `wrapServerAction` |
| Tenant isolation | RLS em `assistant_sessions`/`assistant_messages`/proposals + global tools_registry/providers/models | `packages/db/src/policies/0023_ai_rls.sql` + `0026_ai_rag.sql` |
